# EstateVision: Modern Real Estate Platform

## Project Overview
EstateVision is a comprehensive real estate web application built with React, TypeScript, and Tailwind CSS that delivers a premium property browsing experience with robust authentication features.

![EstateVision Screenshot](https://example.com/screenshot.png)

## Key Features

### Authentication System
- Secure user registration and login flow with protected routes
- Role-based access control system that restricts property and agent details to authenticated users only
- Intuitive UI notifications guiding users to authenticate for accessing premium features

### Property Listings
- Advanced property search system with multi-parameter filtering (price, location, property type, amenities)
- Comprehensive property detail pages with image galleries, amenities lists, and agent contact options
- "Featured properties" highlighting system on both map and list views

### Agent Portal
- Detailed agent profiles showcasing expertise, ratings, and property listings
- Agent filtering by specialty, experience, and location
- "Meet Our Experts" section with featured agent highlights and specialization categories

### Interactive Components
- Mortgage calculator for estimating monthly payments based on loan amount, interest rate, and term
- Property image galleries with thumbnail navigation
- Property location visualization with interactive property cards

### User Experience
- Multiple authentication notifications and UI cues guiding users through the login process
- Responsive layouts that work seamlessly on mobile, tablet and desktop devices
- Toast notifications for user actions and authentication status changes
- Intuitive navigation with protected route indicators

## Technical Implementation
- **React + TypeScript**: Built with strict type checking for improved reliability
- **Context API**: Used for global state management (authentication, theme, favorites)
- **React Router**: Implemented comprehensive routing with protected routes
- **Tailwind CSS + shadcn/ui**: Utilized for consistent, responsive design with dark/light mode support
- **Framer Motion**: Added subtle animations for enhanced user experience
- **Component Architecture**: Developed reusable, maintainable components with clear separation of concerns
- **Mock Data Integration**: Created extensive property and agent datasets for realistic demonstration

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
1. Clone the repository
```bash
git clone https://github.com/yourusername/estate-vision.git
cd estate-vision
```

2. Install dependencies
```bash
npm install
# or
yarn
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to http://localhost:5173
